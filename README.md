**Overview**:SauceDemo is a manual testing project performed on the SauceDemo e-commerce website
**URL:** https://www.saucedemo.com/ 
**scope:** The project covers the major functionalities of the application, including Login, Product Listing and Sorting, Add/Remove Products from Cart, Checkout, Order, Navigation and Logout. 
**tools:** The application was tested using Google Chrome and the tools used for the project include Microsoft Word, Microsoft Excel, Jira and GitHub. 
**document index:** The project documentation includes the Test Plan, Test Scenarios, Test Cases, Test Data, Test Execution Report, Defect Report, RTM and Jira Activities. 
**execution summary:** Test cases were executed for the major functionalities of the application and the passed and failed test cases were recorded. 
**Jira note:** The defects identified during testing were documented and logged in Jira for tracking.
